# 🔐 SECURE ADMIN SYSTEM

> *Secure Your Information, Protect Your Data.*

Sistem informasi manajemen konten berbasis **PHP Native 8.2** (tanpa framework/Composer) yang menerapkan **AES-256-GCM** untuk melindungi isi konten dan **RSA-PSS** untuk autentikasi admin berbasis tanda tangan digital.

---

## ✨ Fitur

| Area | Fitur |
|---|---|
| Publik | Landing page responsif |
| Autentikasi | Login RSA-PSS challenge-response |
| Dashboard | Statistik, aktivitas, grafik |
| Konten | CRUD, pencarian, filter |
| Kriptografi | AES-256-GCM dan RSA-PSS |
| Audit | Log aktivitas admin |
